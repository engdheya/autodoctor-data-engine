# حزمة المراجعة 001 — الأكواد حسب الأولوية

**ليست محتوى معتمدًا.** هذه الحزمة مادة مراجعة بشرية: كل معلومة فيها تحمل مصدرها وحالة
مراجعتها، والمسوّدات العربية والإجراءات موسومة بأنها مسوّدات، ولا يوجد قرار تعارض محسوم.

مبنية من `autodoctor-0.9.0-public.sqlite` (المصادر التجارية: OBDex CC0-1.0 + Wal33D MIT).

## كيف تُراجَع

1. افتح `packs/tier1-001.yaml` واقرأ `english.title_en` مقابل `arabic_draft.title_ar`.
2. صحّح المسوّدة في `translations/ar/priority-001.yaml`، واملأ `translator` و`reviewer`
   واضبط `reviewed: true` — عندها يدخل المحتوى القاعدة عبر `build-db` بدل أن يُتجاهل.
3. للإجراءات: `procedure.quoted_checks` هي جُمل المصدر فقط. اكتب الإجراء (الأدوات، القيمة
   المرجعية، حد القياس، التحذير) أنت أو الفني المؤهل، وأرفقه بالمرجع في `procedure.references`.
4. للتعارضات: استخدم `autodoctor review-conflict <fingerprint> --decision … --reviewer …`.

## إعادة التوليد

```bash
autodoctor review-pack --tier 1 2 --limit 40 --batch 001 \
    --arabic data/translations/ar/priority-001.yaml --write \
    --database data/exports/autodoctor-0.9.0-public.sqlite
```
