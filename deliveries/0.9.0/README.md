## ما هو غائب بقصد، ولماذا

- **بيانات ODbL وCC-BY-SA** (autodiag، OBDb): تُبنى في نسخة داخلية منفصلة وتبقى محجوبة حتى
  تصدر مراجعة قانونية مكتوبة. البناء الداخلي `autodoctor-0.9.0.sqlite` (170,885,120 بايت،
  `sha256` في `docs/BUILDS.md`) **لا يُسلَّم ولا يُوزَّع**.
- **العربية المراجَعة والإجراءات الفحص**: غير موجودة في أي مصدر مرخَّص؛ المسوّدات وقوالب
  المراجعة تأتي وفق الجدول (حتى 2026-11-08)، والاعتماد يحتاج مراجعًا بشريًا وفنيًا مؤهلًا.
- **السيارات/المحركات/ECU في النسخة التجارية**: صفر، لأن المصدر الوحيد لها محجوب ترخيصيًا.
