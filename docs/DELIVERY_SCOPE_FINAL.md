## 3. القيود والبدائل (بصراحة كاملة)

1. **الإجراءات:** غير موجودة في أي مصدر مرخّص. البديل: محتوى مؤلَّف ومعتمد بشريًا (أجهّز المسوّدة والمسار)، أو شراء مجموعة إجراءات مرخّصة (Autodata/HaynesPro/Mitchell1) وأنا أستوردها.
2. **العربية:** لا يوجد مصدر عربي. البديل: مترجم/مراجع بشري يعتمد المسوّدة، أو تسليم التطبيق بواجهة عربية مع محتوى الأكواد بالإنجليزية حتى تُراجَع (وهذا ما تفعله القاعدة الآن: `title_ar` فارغ ولا يُعرض إلا ما هو `reviewed`).
3. **السيارات/ECU:** ODbL وCC-BY-SA يفرضان مشاركة المشتقة بالترخيص نفسه — خطر قانوني على منتج تجاري مغلق. البديل: (أ) موافقة قانونية مكتوبة، (ب) مجموعة بيانات سيارات مرخّصة تجاريًا، (ج) البناء العام بدون ربط سيارات (الحالي) والبناء الداخلي يبقى داخليًا.
4. **التعارضات الحرجة:** لا يمكن حسمها آليًا. البديل: توصية موثّقة لكل تعارض + توقيعك. القاعدة تمنع الإصدار قبل ذلك (D012).
5. **Android:** غير قابل للتشغيل في بيئتي (لا SDK/جهاز). البديل: تشغيلك للأوامر الثلاثة، أو وظيفة CI على GitHub runner بعد دفع ملف الـworkflow.
6. **`v1.0.0`:** لا يُنشأ وسم قبل اكتمال كل بنود القبول — بما فيها العربية المراجَعة والإجراءات المعتمدة. هذا التزام صريح بقاعدتك.
