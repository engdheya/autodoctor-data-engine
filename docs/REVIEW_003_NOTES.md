## 1. تصنيف الاقتباسات (الملاحظة 1)

كل اقتباس صُنّف بقاعدة معلنة، وكل تصنيف يحمل `rule` و`matched` (الكلمات التي فعّلت القاعدة)
وحالة `rule_based_unreviewed` — أي أن التصنيف نفسه مادة مراجعة لا حكم نهائي.

| الفئة | عدد الاقتباسات |
| --- | --- |
| `diagnostic_check` — فحص تشخيصي فعلي | **415** |
| `monitoring_description` — وصف مراقبة النظام | **1,500** |
| `technical_explanation` — شرح تقني | **616** |
| `non_procedure` — ليس إجراءً | **3,450** |
| **المجموع** | **5,981** |

أكواد فيها `diagnostic_check` واحد على الأقل: **412** (من 8,038 كودًا في الطبقتين 1 و2).
قاعدة الحسم: صيغة أمر/إلزام + كائن مادي أو أداة أو قيمة، **ولا يكون الفاعل** وحدة تحكم أو
شركة مصنّعة أو صيغة وصفية («بعض المحركات تقيس…»). لذلك جملة مثل *«GM checks the whole pack»*
ليست إجراء فحص.

## 2. نطاق الانطباق (الملاحظة 2)

فُصل الحقلان:
- `dtc_definition_scope`: هل **تعريف** الكود عام (SAE J2012 / ISO 15031-6) أم خاص بمصنّع.
- `procedure_applicability`: **`unverified` دائمًا**، مع `applicability_note` صريحة:
  «عمومية تعريف الكود لا تجعل الفحص المنقول صالحًا لكل سيارة تُبلغ به؛ الانطباق على الشركة
  والموديل والسنة والمحرك يثبته الفني من المراجع».
- `source_mentions`: ما طبعه المصدر نفسه من أسماء سيارات/محركات، مع الجملة، وحالته
  `source_text_mention` لا ادّعاء انطباق.

## 3. مراجعة العربية (الملاحظات 3 و4)

100 مسوّدة، وكل واحدة تحمل الآن:
- `context_ar`: سياق المصدر (GM، Ford، Subaru، Toyota…) عندما يكون الوصف الإنجليزي خاصًا بمصنّع،
  مع نص القيم المنقولة (مثل 5V و1V في P057C) وربطها بسياقها.
- `review.checks`: فحص آلي لثلاثة أمور — بقاء سياق المصنّع، بقاء قيم القياس، وجود ملاحظة السياق.
- `review.status`: `machine_checked_pending_human` أو `needs_fix`.
- `source`: المصدر الإنجليزي الذي تُرجم عنه، ونطاقه (تعريف عام / خاص بمصنّع).
