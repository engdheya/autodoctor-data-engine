# حزمة المراجعة 002 — الإجراءات المنقولة + 100 كود سلامة بالعربية

**مادة مراجعة، لا محتوى معتمد.** كل رقم أدناه مقيس من `autodoctor-0.9.0-public.sqlite`
ومن مخرجات `autodoctor procedure-export` و`autodoctor review-pack`.

## 1. الإجراءات: ما وُجد في المصادر فعلًا (الطبقتان 1 و2)

| المقياس | العدد |
| --- | --- |
| أكواد الطبقتين (سلامة + أنظمة حيوية) | **8,038** |
| أكواد فيها جُمل فحص **منقولة حرفيًا** من وصف المصدر | **3,981** (49.5%) |
| جُمل الفحص المنقولة | **5,930** |
| جُمل منها تحتوي رقم قياس | **709** (داخل النص المنقول فقط) |
| أكواد يذكر المصدر فيها سيارة/محركًا بالاسم | **1,760** |
| أكواد **لا يوجد** فيها أي نص فحص في المصادر | **4,057** — معلنة صراحة بلا بديل |
| **إجراءات معتمدة** | **0** |

كل جملة منقولة تحمل: النص الإنجليزي، المصدر، حالة `quoted_unreviewed`، و`verbatim: true`
بعد التحقق من أنها **جزء حرفي** من الوصف المخزّن. وأي رقم قياس يظهر داخل الاقتباس يُدرج
تحت `measurement_mentions` بوصفه **منقولًا غير مُتحقَّق منه** — ولا يُنسخ إلى حقل قيمة.

الحقول `tools` و`nominal_values` و`limits` و`warnings` **تبقى فارغة دائمًا** من المحرك،
واختباران يفشلان إذا امتلأت، وثالث يفشل إذا لم تكن الجملة حرفية.

### نطاق الانطباق

لكل كود في `procedures-quoted.yaml`:
- `identity_scope`: هل التعريف عام (SAE J2012 / ISO 15031-6 يصلح لكل سيارة تُبلغ به) أم خاص بمصنّع.
- `source_mentions`: أسماء السيارات/المحركات التي **طبعها المصدر نفسه** (مثل Subaru، Ford، diesel، V6) مع الجملة التي وردت فيها.
- `status: source_text_mention` أو `not_stated` — وليس ادّعاء انطباق مُتحقَّق منه؛ التحقق مسؤولية الفني.

## 4. ما ينتظر اعتماد المختص

1. **3,981 كودًا** فيها نص فحص منقول: يحتاج كل واحد كتابة إجراء كامل (أدوات، قيمة مرجعية، حد، تحذير، انطباق) واعتمادًا باسم الفني.
2. **4,057 كودًا** لا يوجد لها أي نص فحص في المصادر المرخّصة: قرار المنتج إما استبعادها من عرض الإجراءات أو توفير مصدر مرخّص.
3. **100 مسوّدة عربية**: مراجعة لغوية + فنية ثم `reviewed: true` واسم المترجم والمراجع.
4. **14 تعارضًا حرجًا**: لم يُحسم أي منها آليًا.
